1. What is Excel?

Microsoft Excel is a spreadsheet application developed by [Microsoft](https://www.microsoft.com?utm_source=chatgpt.com) used to store, organize, calculate, and analyze data using rows and columns.

---

2. What is a workbook?

A workbook is an Excel file that contains one or more worksheets (spreadsheets).
Example: `sales.xlsx` is a workbook.

---

3. What is a spreadsheet?

A spreadsheet is a page made up of rows and columns used to enter and manage data. Each box is called a cell.

---

4. When was Excel developed?

Excel was first developed in **1985** for Apple Macintosh computers.

---

5. Why is Excel used?

Excel is used for:

* Data entry
* Calculations
* Creating charts and graphs
* Data analysis
* Budgeting
* Reporting
* Managing records

---

6. What is the difference between Excel and MySQL?

| Excel                       | MySQL                           |
| --------------------------- | ------------------------------- |
| Spreadsheet software        | Database management system      |
| Stores data in worksheets   | Stores data in databases/tables |
| Best for small-medium data  | Best for large data             |
| Easy GUI interface          | Uses SQL queries                |
| Used for analysis/reporting | Used for backend data storage   |

MySQL is mainly used for managing databases, while Excel is mainly used for spreadsheet operations.
